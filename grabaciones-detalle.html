Carga Masiva desde Excel

Para auditar muchas cámaras de una sola vez. El archivo debe tener estas columnas en la primera fila: Numero, Camara, TipoCamara, NVR, Estado (OPERATIVO / INOPERATIVO / vacío), DiasGrabacion (días de grabación disponibles en el NVR), Auditor, FechaAuditoria (AAAA-MM-DD), Observaciones. Se identifica cada fila por el código de Cámara: si ya existe en esta sede, se actualiza; si no, se agrega. El rango "Grabación desde–hasta" se calcula solo a partir de DiasGrabacion, no hay que cargarlo aparte.
